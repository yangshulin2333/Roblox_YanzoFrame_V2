# UI 与 Studio 对象边界

## 核心规则

手工可见的对象，默认由 Studio 管。

代码只负责运行时行为。

## Studio 管什么

- 位置
- 大小
- 颜色
- 层级
- 字体
- 布局
- 主要 UI 结构
- Workspace 中手工摆放的物体

## 代码管什么

- 找到对象
- 绑定按钮点击
- 改文本
- 改数字
- 显示 / 隐藏
- 启用 / 禁用
- 播放简单反馈
- 克隆明确的 Template

## 对象类型

| 类型 | 谁创建 | 谁调整 | 代码能做什么 |
|---|---|---|---|
| 手工对象 | Studio | Studio | 查找、绑定、改状态 |
| Template | Studio | Studio | 克隆、填数据、显示 |
| 测试对象 | 代码 | 代码 | 用完可清理 |
| 特效对象 | 代码 | 代码 | 短时间显示后销毁 |

## 实现前必须说明

每个涉及 UI 或 Workspace 的模块，实现前都要先写清楚：

- 对象放在哪里
- 对象叫什么名字
- 谁负责调整位置
- 代码允许改哪些属性
- 代码不允许改哪些属性

没有这张边界表，不进入 UI 代码实现。
